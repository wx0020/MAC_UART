# MAC UART 串口工作台

[English](README.md) · 简体中文

MAC UART 是一款原生 macOS 串口与 TCP 调试工具，适用于嵌入式设备、USB 转串口模块和读卡器联调。你可以发送二进制指令，以 HEX 查看设备回复，再把常用指令保存下来。做长时间测试时，可以按顺序轮询多条指令，同时将收发记录持续写入磁盘。

## 连接设备

| 模式 | 操作 |
| --- | --- |
| 串口 | 选择检测到的 `/dev/cu.*` 端口和波特率，点击「打开串口」。默认 115200 波特率、8 数据位、无校验、1 停止位、无流控。 |
| TCP 客户端 | 输入服务端 IP 或主机名及端口，点击「连接」。 |
| TCP 服务端 | 输入本地端口，点击「开始监听」。多个客户端接入后，可在「发送至」选择目标，日志会标明对应的客户端地址。 |

通过「串口 → 串口参数设置…」（⌘,）可调整波特率、数据位（5–8）、校验位（无、奇、偶）、停止位（1 或 2）和流控（无、RTS/CTS、XON/XOFF）。修改前先关闭串口，设置会自动保存，下次打开时生效。

## 收发数据与快捷指令

- 选择「文本」可发送 UTF-8 字符串，行尾可选无、CR、LF 或 CR LF。选择「HEX」可发送原始字节，例如输入 `41 0D 0A` 会发送三个字节。点击「发送」或按 ⌘Return 即可发送。
- 收发日志显示毫秒时间戳和 RX/TX 方向，底部统计收发字节数。日志显示格式与发送格式独立，已有记录也能切换文本或 HEX 查看。
- 点击「存为指令」即可保存名称、内容、格式与行尾。连接设备后，点击右侧已保存的指令即可发送。

## 定时发送与多指令轮询

在发送区点击「自动发送…」。「定时发送」重复发送当前输入，「多指令轮询」从上到下发送勾选的快捷指令。可用上下箭头调整顺序，也可以为每条指令单独指定间隔。

例如，要重复执行 100 轮「查询设备 → 读取状态」，先保存这两条指令，按顺序勾选，将默认间隔设为 `1000` ms、循环次数设为 `100`。间隔从上一条发送完成时开始计算。循环次数 `0` 表示持续运行。点击「停止自动发送」可随时结束，设备或目标 TCP 客户端断开时也会停止。

## 导出日志与连续录制

| 操作 | 写入内容 |
| --- | --- |
| 「导出日志…」（⇧⌘E） | 按当前文本或 HEX 显示格式，将界面缓存中的记录保存为 UTF-8 文本。缓存最多保留 3000 条记录，通常约 1 MiB 原始数据。 |
| 状态栏「连续录制…」 | 选择目录后开始写入新增的收发记录，格式沿用开始录制时的选择，每卷约 10 MiB，文件按序编号。清空界面日志不影响录制，点击「停止录制」即可结束。 |

两种方式都会保存日期、毫秒时间戳、收发方向及串口路径或 TCP 对端地址。以下是一条 HEX 日志示例。

```text
[2026-11-19 10:42:15.083] TX [/dev/cu.usbserial-01] 41 0D 0A
```

## 运行与构建

项目最低部署目标为 **macOS 14**，当前本机构建的应用适用于 **Apple 芯片 Mac**。如果已有打包好的应用，可直接打开 `dist/MAC_UART.app`。从源码构建需要安装支持 macOS 开发的 Xcode，项目已使用 Xcode 27.2 编译通过。

在项目根目录执行以下命令。

```bash
xcodebuild -project "MAC UART/MAC UART.xcodeproj" -scheme "MAC UART" \
  -configuration Release -derivedDataPath build \
  CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY=- DEVELOPMENT_TEAM= build
open "build/Build/Products/Release/MAC UART.app"
```

界面默认跟随系统语言，可在菜单栏「界面语言」中手动选择简体中文或 English。
