常见问题

列表里没有串口？ 重新插入设备并点击串口旁的刷新按钮。确认转接器已被 macOS 识别，并检查其他程序是否占用了端口。

接收文字异常？ 先切换 HEX 核对字节，再检查波特率、校验位和设备字符编码。文本模式使用 UTF-8。

怎么保存整晚的日志？ 在测试开始前点击「连续录制…」并选择目录；结束时点击「停止录制」。导出功能保存当前屏幕缓存。

MAC UART Support

Email xiangw@itron.com.cn with your macOS version, app version, connection mode and steps to reproduce the problem. Remove credentials, card data and other sensitive information before sending any example logs.

Common questions

Missing serial port? Reconnect the device, refresh the port list, check that macOS recognises the adapter and close any other app using the port.

Unexpected text? Switch the log to HEX to inspect the bytes, then check baud rate, parity and device encoding. Text mode uses UTF-8.

How do I keep an overnight log? Choose Record traffic before starting the test, select a folder, then choose Stop recording when finished. Export log saves the current display buffer.
