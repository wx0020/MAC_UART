# MAC UART · English (Australia)

## Name

MAC UART

## Subtitle

Serial & TCP Device Console

## Promotional text

Send a command, inspect the reply in HEX, then repeat the exchange on a timer. Record a long session to disk while you keep working in the traffic log.

## Keywords

serial,TCP,terminal,hex,debugging,embedded,firmware,RS232,RS485,logger,testing

## Description

MAC UART helps you see exactly what passes between your Mac and a device. Type a UTF-8 command or send raw HEX bytes, then read the reply alongside the millisecond timestamp and the RX or TX marker. Switch the log between text and HEX to inspect the same exchange in both views.

Connect over serial or TCP
Choose a detected serial port and set the baud rate, data bits, parity, stop bits and flow control. To test over a network, connect to a device as a TCP client or listen as a TCP server. When several clients are connected, select the one that should receive your next command.

Repeat a bench test
Save a command with its data format and line ending. Send it with one click, repeat it at an interval, or arrange several commands into a sequence. Set a round count for a repeatable test, or let the sequence run until you stop it.

Keep the traffic you need
Export the current log as a text file, or start continuous recording before a longer test. Recording writes new traffic to the folder you choose and splits it into numbered files of about 10 MiB each. You can clear the on-screen log while recording continues.

The interface supports English and Simplified Chinese. No account is required.
