MAC UART 1.0 (2) · macOS

No account, subscription or sign-in is required. The TCP console can be reviewed on one Mac without external hardware.

1. Open MAC UART, select TCP Server, enter port 19001 and click Start listening. If the port is in use, choose another unused port in both the app and the command below.
2. In Terminal on the same Mac, run:
   nc 127.0.0.1 19001
3. In Terminal, type PING and press Return. The app shows a timestamped RX entry for the connected peer. Select HEX in the traffic log to inspect the received bytes.
4. In the app's send area select Text, type PONG, select LF as the line ending and click Send. Terminal displays PONG, and the app logs a TX entry.
5. Optional: click Save as command and give the command a name. Open Automatic sending, choose Command sequence, select the saved command, set 1000 ms and 3 rounds, and start. Terminal should receive three more replies.
6. Optional: click Record traffic, choose a folder and exchange another message. Click Stop recording, then open the numbered .txt file in that folder.
7. Stop listening and close the Terminal session.

Serial mode requires a macOS-recognised serial device. For network testing, the app connects to the host the user specifies or accepts connections on a port the user opens. File access is used for user-initiated export and recording.
